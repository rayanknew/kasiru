# Kasiru

**Шлюз между вашими программами и API языковых моделей, в котором приватность решается в одном месте.**
Один OpenAI-совместимый адрес; код называет *уровень* и *класс данных*, Kasiru решает, какая модель увидит текст и в каком виде.

```
ваши программы ──► Kasiru ──► локальная модель (llama.cpp / Ollama)      ← secret и всё, что не удалось очистить
       │                  ──► облако после обратимого обезличивания      ← personal
       │                  ──► облако как есть                            ← public
       └── audit.jsonl: кто, куда, сколько токенов, сколько замен, ноль утечек — и никогда сам текст
```

Имя от аккадского *kaṣāru* — «связывать воедино». Проект вырос из домашней системы одного человека: несколько помощников и конвейеров над личными заметками, перепиской и расшифровками встреч на русском, украинском и английском, бесплатные облачные тарифы и небольшая локальная модель как последний резерв.

## Зачем ещё один шлюз

Большинство прокси для моделей делают одно из двух: вырезают персональные данные или маршрутизируют между провайдерами. Kasiru делает оба в одной точке решений и добавляет то, чего мы не нашли:

- **Класс данных задаёт клиент, шлюз его исполняет.** `secret` не покидает машину. `personal` уходит только после обезличивания и только если проверка утечек прошла. `public` уходит как есть.
- **Уровни вместо моделей.** `local | cheap | good | best | long` — упорядоченные списки кандидатов с дневными квотами (запросы, токены, доллары), остыванием после 429/5xx и локальным бэкендом в конце. Система деградирует в *медленную*, но никогда в *недоступную*; бесплатное тратится раньше платного.
- **Обратимые постоянные псевдонимы.** Одна сущность — один токен навсегда (`[person-7]`): облачная модель видит связи между людьми, а ответ возвращается с настоящими именами, в том числе внутри аргументов вызовов инструментов.
- **Кириллица на первом месте.** Русский NER на CPU (Natasha), украинский (spaCy), словарь по леммам («Северного Ветра» = «Северный Ветер»), ё/е, дефисные имена, отчества. Новый язык — один адаптер.
- **Симметричные фильтры.** Чего не находит замена, того проверка утечек не считает утечкой, поэтому особенность словаря не уводит молча все запросы в локальную модель.
- **Разметка секретов.** Строки с `[secret]` (и `[чувствительно]`) и блоки `<secret>…</secret>` никогда не уходят во внешний API: весь запрос остаётся локальным, либо в режиме *split* секретные строки обрабатываются локально и подшиваются к облачному ответу.
- **Агенты работают сквозь шлюз.** `tools` / `tool_calls` проходят; локальные маршруты стримятся по-настоящему.
- **Только стандартная библиотека.** Ядро работает без зависимостей на Python 3.9+. Детекторы, валидаторы и морфология — необязательные дополнения.

## Установка

```bash
pip install "kasiru[all] @ git+https://github.com/rayanknew/kasiru"
python -m spacy download uk_core_news_lg   # только для украинского
kasiru init      # ~/.config/kasiru/{kasiru.json,env,entities.json}
kasiru check
kasiru serve
```

## Использование

```bash
curl http://127.0.0.1:8081/v1/chat/completions \
  -H "Authorization: Bearer $KASIRU_KEY_SCRIPTS" \
  -H "X-Data-Class: personal" -H "X-Project: notes" \
  -d '{"model": "good", "messages": [{"role": "user", "content": "Сведи мой разговор с Иваном Примеровым"}]}'
```

Подходит любой OpenAI-совместимый клиент: базовый адрес — Kasiru, модель — имя уровня. В ответе есть поле `kasiru`: класс, бэкенд, маршрут, замены, цена, миллисекунды.

- `kasiru scrub файл.txt` показывает, что именно увидит облако.
- `kasiru entities pending|keep|ignore` — просмотр находок детектора.
- `kasiru report --days 7 --by project` — сводка по журналу.
